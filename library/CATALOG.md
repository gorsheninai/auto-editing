# Библиотека сцен

Сцену можно назвать в раскадровке по имени из этого каталога, например «здесь MCycle» или «здесь S3Jobs». Код в `motion.tsx` и `three3d.tsx`: туда копируются сцены из каждого нового ролика.

## Библиотека блоков (`template/src/blocks/`) — готовы для сборки Story

Подключены к композиции Story: код блока в начале описания сегмента раскадровки (`MBars: я — 3 | они — 30 | заголовок: клиентов в месяц`) — `pult_to_story.py` ставит `scene`, данные берутся из описания после кода. Переходы `Tr…` пишутся в описании сегмента, НА который переходим (`tr`), эффекты `Fx…` — в `fx`, пометки — в `ov` (координаты кадра 1080×1920, по умолчанию центр). Подложка `BgGrain` — «живой градиент» в настройках ролика. Список кодов — `template/src/blocks/codes.json`. Превью каждого блока — на пульте.

Источники: [remocn](https://github.com/remocn/remocn) (MIT) и [video-shotcraft](https://github.com/Vincentwei1021/video-shotcraft) (Apache-2.0, он же getshotpack.com), лицензии — в template/src/blocks/licenses/; часть блоков remocn в `template/src/remocn/` (импорты переписаны, шрифты локальные, фон прозрачный, свой движок страниц субтитров); сцены с цифрами написаны для студии по идеям remocn и remotion-scenes. Стенд превью: `npx remotion bundle src/blocks/entry.ts`, композиции `P-<код>`.

| Код | Как выглядит |

| SubWord | На экране одно крупное слово, каждое выпрыгивает в момент произнесения |

| SubMarker | Ключевые слова подчёркиваются маркером в момент произнесения |
| SubStamp | Ключевые слова падают как резиновая печать |

Настройки ролика с пульта: `punch` — наезды камеры на ударных словах в режиме A, `progress` — полоса прогресса вверху. Ken Burns для картинок работает всегда. Текст пометок и эффектов берётся из описания: «Notify: Телеграм — Новый заказ», «NameTag: Иван Петров — маркетолог», «FxFreeze: вот этот момент».
