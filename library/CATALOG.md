# Библиотека сцен

Сцену можно назвать в раскадровке по имени из этого каталога, например «здесь MCycle» или «здесь S3Jobs». Код в `motion.tsx` и `three3d.tsx`: туда копируются сцены из каждого нового ролика.

## Моушн-графика (`motion.tsx`)

| Имя | Что на экране | Подходит для |
|---|---|---|
| MPath | Змейка из 4 пронумерованных узлов, линия рисуется штрихом, узлы загораются на словах, в конце плашка «↑ рост» | Путь, этапы, «раньше было так» |
| MRace | Карточка зачёркивается, появляются штампы («быстро», «дёшево»), затем две дорожки-прогрессбара ×1 и ×10 со счётчиками | Сравнение, «человек и ИИ», скорость |
| MCycle | Центр («ты управляешь»), 4 узла по кругу, дуги рисуются по шагам, по замкнутому кругу бегает точка | Процесс, цикл, роль человека |

Общие детали: заголовок блока состоит из курсива и гротеска. Узел — белый круг с цветным кольцом, внутри стикер, на нём бейдж с номером, подпись крупная, 50 px.

Мелочи: `Popup` (ретро-окно в коде: красная плашка, ×, текст), `Glob` + `G` (дочерние компоненты видят глобальный кадр — для сцен, которые тянутся через несколько сегментов без шва), `POINT` (пиксельный человечек с указкой).

## 2D-сцены из слоёв (`reels/*/src/Scenes.tsx`)

Сцена складывается из фона, вырезанной позы и предметов: предметы появляются с пружиной, к ним добавляются подписи-плашки.

Правило: у сцены есть мини-сюжет, и на ключевом слове её состояние меняется. Пример из SPhone: у телефона на экране появляется «Доступна новая версия» ровно на слове «изменилась».
