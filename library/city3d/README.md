# city3d — макет квартала под стеклом (ролик «Отключат интернет»)

Весь ролик — одна 3D-сцена: квартал-миниатюра из моделей Kenney на подиуме, стеклянный короб, отрывной календарь на столе,
камера летает по ключам `CAM`, этапы меняют свет и сезон (`LIGHT`, `seasonAt`), события по словам через `wf()`.

Файлы:
- `lib.tsx` — время и `wf`, загрузка GLB через delayRender с запеканием палитры в цвета вершин, `Model` (tint/snow),
  `canvasTex` (надписи на текстурах), `Blob` (мягкая тень-пятно), `Person` (фигурка для макета: позы, шаг, сутулость, предмет в руке), `useFonts`.
- `props.tsx` — Calendar, AppIcon (нейтральные значки без логотипов), Phone + updateTex, Shield, Reload, Bubble, Truck, Flash, Laptop, Star, Bench, Kiosk, Globe, signTex.
- `City.tsx` — сцена ролика целиком: карта, камера, свет, 13 сцен-событий. Как образец: менять MAP/CAM/сцены под новый текст.
- `sfx_city.py` — тихие SFX синтезом numpy по словам; `finish3d.py` — 720×1280 → 1080×1920, tilt-shift маской, виньетка, зерно,
  субтитры PNG-плашками (Inter Tight 700 56), голос+SFX, loudnorm (LN_MEASURED — замер первого прохода).
- `render_chunk.sh` — рендер куска кадров композиции City3D; `stills.mjs` — стоп-кадры одним браузером.
- Модели: `tools/fetch_kenney.sh reels/NN/public/models` (в git не храним).

Скорость программного рендера (swangle, 2 ядра) — главное ограничение:
- MeshStandard + текстура → Lambert с цветами вершин: ×2–3 быстрее; anisotropy только 1.
- Карты теней (особенно soft/PCF) — самое дорогое; заменены пятнами `Blob`.
- backdrop-filter в браузере дорогой — размытие «макета» делать в ffmpeg.
- 3D рендерить в 720×1280 и масштабировать: ~4 с/кадр на общих планах, ~2 с на крупных; 62 с ролика ≈ 2 ч двумя кусками
  (фоновая команда живёт до 2 ч — резать на куски по ~940 кадров).
