# Пакетный запрос для GPT Image 2.5

Пользователь сам отправляет запрос в ChatGPT (режим work / агент) вместе с фото и видео референсов, и ChatGPT за один заход генерирует ВСЕ картинки для ролика. Моя задача — выдать этот запрос целиком, готовым к копированию. Картинки я не генерирую и кредиты не трачу.

Главное правило: картинки создаются КОНКРЕТНО под смысл этого текста, в стиле этих референсов. Никаких наборов «по умолчанию»: от ролика к ролику содержимое разное, потому что разный текст.

## Когда запускать
После того как есть: текст, стиль (стилевой паспорт) и, по возможности, раскадровка. Если стиля или текста нет — сначала они, промпты вслепую не писать. Если работа идёт с пульта (проект в ArtifactData), брать оттуда script, styleAnalysis, sbRows и assetPlan.

Картинки нужны только двум типам сегментов раскадровки:
- `l2d` — 2D-сцена из слоёв → позы, предметы, руки, фоны;
- `gen` — картинка по смыслу → одно цельное изображение на сегмент.
3D, моушн, кинетический текст и вставки пользователя картинок не требуют. Если раскадровки нет — план по всему тексту.

## Шаг 1. Смысловой план (до промпта)
1. Внимательно прочитать каждое предложение текста. Разбить текст (или только 2D-сегменты раскадровки) на СМЫСЛОВЫЕ блоки по мыслям, 3–10 штук.
2. Для каждого блока: точная цитата, мысль для зрителя, визуальная метафора ИМЕННО для этой мысли — с конкретными деталями из текста (имена, цифры, предметы, места, профессии, действия). Если есть раскадровка — опираться на её визуал в первую очередь.
3. Посмотреть на кадры референсов: как там выглядят персонажи, предметы, фоны, материалы, свет — элементы должны выглядеть как из этих референсов.
4. Вывести, что генерировать, и привязать КАЖДЫЙ элемент к блоку или сегменту:
   - позы персонажа (до 9) — что делает и с каким выражением;
   - предметы — каждый из смысла своего блока, с формой, материалом, цветом, деталью;
   - руки от первого лица — ТОЛЬКО если блоку нужно действие руками, и только с предметами из текста;
   - люди/аватарки — только если в тексте есть аудитория, клиенты, команда, толпа;
   - фоны 3–5 — места, которые следуют из текста;
   - картинки по смыслу — по одной на каждый gen-сегмент: что ровно изображено (картина, скриншот чата или приложения, документ, обложка, фото предмета или места), точный короткий текст на ней, если нужен, и формат (B — 1024×1024, C — 1024×1536).
5. Запрещено: стоковые предметы, которых нет в тексте и которые не следуют из его смысла (телефон, ноутбук, лупа, лампочка, ракета, шестерёнки, графики, мишень, пазл и т.п. — только если текст про это). Две разные мысли не получают одинаковую метафору.
6. Картины и скриншоты: старые картины с истёкшими правами — можно узнаваемо; работы современных художников — только «в духе», без копии. Скриншоты и документы — с нейтральным интерфейсом, без логотипов и названий реальных сервисов, СМИ и компаний. Настоящий скриншот новости или поста пользователь кладёт сам как «Мои вставки».
7. Показать план пользователю коротко или записать в проект пульта (assetPlan: blocks, poses, props, hands, people, backgrounds, pictures).

## Шаг 2. Запрос строго по плану

**Референсы с ролями** — «Фото 1 — лицо и личность», «Видео 1 — только стиль, палитра, свет, материалы — не копировать кадры и персонажей».

**Стилевой блок** (один на весь запрос, 5–8 строк): эстетика, материалы и фактура, свет, палитра hex-кодами, ракурс/камера, степень детализации, чего избегать.

**Персонаж**: «same person as Photo 1 — keep face, proportions, hairstyle, glasses, outfit identical in every cell». Попросить ChatGPT сначала самому коротко описать внешность по Фото 1 и повторять описание в каждом листе с персонажем.

**Набор файлов — четыре группы, состав из плана:**
1. Персонаж без фона (только если в плане есть позы или руки): 01_turnaround.png — разворот 4 ракурса; 02_poses.png — позы (2×2 до 4, 3×3 до 9); руки — отдельный лист.
2. Предметы без фона: листы по 9 (3×3), последний может быть 2×2; люди — лист 4×4, только если нужны.
3. Фоны без людей: по файлу на каждый фон из плана, вертикальные, с пустым центром.
4. Смысловые изображения: pic_N.png на каждый gen-сегмент — цельная непрозрачная композиция, размер по формату (B — 1024×1024, C — 1024×1536), стиль из общего стиля; текст на картинке — точно, в кавычках, с местом и количеством повторов; персонаж пользователя только если план этого прямо требует.
Готовые сцены с персонажем на фоне для 2D-сцен НЕ заказывать — они собираются слоями в монтаже.

Перед каждым пунктом одной строкой по-русски: «Для: «цитата из текста»».

## Правила промптов (GPT Image 2.5)
- Порядок в каждом пункте: что за изображение → объект → сетка и содержимое КАЖДОЙ ячейки по номеру (конкретно, как в плане) → стиль/свет/материал из общего стиля → ограничения.
- Конкретные визуальные слова вместо «эпично, премиально, 8K, masterpiece».
- В пунктах групп 1–3: `no text, no letters, no numbers, no logos, no watermark`. В смысловых изображениях текст допустим только тот, что указан в плане, и `no logos, no watermark` всегда.
- Прозрачный фон (группы 1–2): `isolated on a fully transparent background, PNG with alpha, no backdrop, no floor, no cast shadow, no checkerboard pattern, clean edges, no halo`.
- Сетки: «N equal cells, each item fully inside its cell with generous empty margin, nothing crosses cell borders, same scale and same light direction in every cell».
- Размеры: листы 2048×2048, фоны 1024×1536, смысловые — по формату. Писать размер явно в каждом пункте.
- Промпты на английском (текст на картинке — на нужном языке, обычно русском), служебные инструкции агенту — на русском.

## Формат выдачи
Один блок кода — весь запрос целиком. Структура:

```
ЗАДАЧА
Сгенерируй все изображения из списка ниже по очереди, каждое отдельным файлом. Не задавай уточняющих вопросов, не пропускай и не объединяй пункты. После каждого изображения проверь его по разделу ПРОВЕРКА; если не прошло — перегенерируй. В конце дай список файлов.

РЕФЕРЕНСЫ
Фото 1 — лицо и внешность пользователя
Видео 1 — … (только стиль, палитра, свет, материалы)

ОБЩИЙ СТИЛЬ
…

ПЕРСОНАЖ
…

ИЗОБРАЖЕНИЯ
01_turnaround.png — Для: (весь ролик) — 2048×2048, transparent …
02_poses.png — 2048×2048, transparent, 3×3: 1) Для: «…» — …
04_items_A.png — Для: «…» …
bg_1.png — Для: «…» — 1024×1536, opaque …
СМЫСЛОВЫЕ ИЗОБРАЖЕНИЯ
pic_1.png — Для: «…» — 1024×1536, opaque, text on image: «…» exactly once, top …

ПРОВЕРКА
- прозрачность без шахматки и белой подложки (кроме фонов и pic_N);
- ровно N ячеек, ничего не заходит на соседнюю;
- лицо и одежда совпадают с Фото 1;
- в группах 1–3 нет текста; в pic_N текст ровно как в пункте, без ошибок; нигде нет логотипов;
- стиль совпадает с общим стилем;
- каждая картинка соответствует своему куску текста.
```

Каждый пункт — полный самостоятельный промпт (без «как в предыдущем»), чтобы его можно было отправить и отдельно.

После блока — коротко:
- какие файлы референсов приложить и в каком порядке;
- если ChatGPT остановится — написать «продолжи с пункта N»;
- если лист не удался — точечная правка «Измени только …, сохрани …»;
- если ChatGPT отказался рисовать картину или скриншот — правка «в духе …, без копии» или замена на вставку пользователя.

## После генерации
Пользователь кладёт файлы в папку ролика на Диске. Я проверяю: сходство персонажа, прозрачность, целостность сетки, текст на pic_N, единый стиль, соответствие тексту — и говорю, какие пункты перегенерировать (с готовым текстом правки).
