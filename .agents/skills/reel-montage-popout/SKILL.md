# Монтаж рилса с говорящей головой

Пользователь присылает текст сценария, видео со своим ИИ-аватаром, референсы стиля и бриф. От ролика к ролику меняются стиль и параметры брифа. Шаги, правила и техпроцесс постоянные, их НЕ переспрашивать.

## 0. Студия (код и наработки)
- Весь код хранится в GitHub `gorsheninai/auto-editing` (приватный): шаблон Remotion, `library/` (моушн-блоки, 3D-предметы и сцены, `CATALOG.md`, короткий указатель `INDEX.md`), `tools/` (reel_prep.py — подготовка ролика одной командой, render.sh и др.), `brief.md`, ролики в `reels/NN-name/`.
- В начале работы подключить репозиторий (`add_repo` с access push → clone → `register_repo_root`) и читать только то, что CLAUDE.md называет под задачу. CATALOG.md целиком не читать: для подбора блоков — `library/INDEX.md`, описание нужного блока — Grep по коду в CATALOG.md.
- Видео и картинки в git НЕ коммитить: они лежат на Google Диске в папке ролика. Запасная копия кода — архив `reels-studio.zip` на Диске.
- После ролика удачные новые блоки перенести в `library/` и `CATALOG.md` (затем `python3 tools/catalog_index.py`), убрать копии шаблона `python3 tools/reel_slim.py reels/NN-name`, закоммитить и запушить в main.

## Шаблон: 9 шагов (у каждого: постоянно / параметры / на выходе)

1. **Идея.** Параметры: тема, угол подачи, цель (охват, подписка, продажа, слово в директ).
2. **Текст.**
   - Постоянно: хук в начале, сторителлинг, призыв в конце, факты и цифры проверить веб-поиском.
   - Параметры: длина, тон, призыв.
   - На выходе: утверждённый сценарий.
3. **Запись.**
   - Параметры: голос, аватар, фон (однотонный вырезается чище).
   - Видео аватара пользователь загружает на пульт (до 20 МБ) или присылает файлом в чат.
4. **Стиль.**
   - Постоянно: разбор референсов — видео (ритм, раскладки, переходы, подача текста, звук) и картинок (палитра, материалы, свет, ракурсы, шрифты). Предложить 3–5 вариантов текстом, пользователь выбирает. Один визуальный язык на ролик.
   - На выходе: стилевой паспорт — описание и общий блок стиля для промптов.
   - Пользователь не любит неон и «просто 3D» без эстетики. Любит, когда стиль работает как метафора (PS2: VS-экран, «новый предмет», «уровень повышен»).
5. **Раскадровка** — текстом, до генерации и монтажа.
   - Каждая фраза → сцена и режим. Для каждой вставки указать: что видим, что меняется, на каком слове.
   - Параметры: доли режимов (пресет), набор типов вставок, ритм.
   - Ждать «ок».
6. **Материал.**
   - Список картинок выводится из раскадровки.
   - Промпты собираются скиллом `gpt-image-batch-prompts`: один большой запрос для ChatGPT в режиме work, только три группы — персонаж без фона, предметы без фона, фоны без людей.
   - Готовые сцены с персонажем не генерировать.
   - Пользователь кладёт результат на Диск и нажимает на пульте «Собрать пакет для монтажа»; я проверяю лист подготовки и даю точечные правки.
7. **Монтаж** — после «делай».
8. **Правки** — точечно по готовому видео.
9. **Публикация и разбор.** Через пару дней пользователь присылает цифры (досмотры, сохранения, кодовое слово), выводы идут в следующую идею.

Бриф: `brief.md` в репозитории. Всё, что не указано, берётся по умолчанию (значения ниже).

## Постоянные правила монтажа

**Звук** (`tools/cut_pauses.py`)
- Вырезка пауз: `silencedetect=noise=-38dB:d=0.12`, паддинг 0.05 с, куски короче 0.18 с выкинуть (вдохи), микрофейды 15 мс. В роликах с пульта паузы уже найдены пультом (поле segs) — reel_prep режет ровно по ним.
- Ускорение: по умолчанию ×1.2 (`setpts=PTS/1.2,fps=30` + `atempo=1.2`).
- Громкость: `loudnorm=I=-14:TP=-1.5:LRA=11`.
- Без музыки, если не попросили. Тихие SFX (громкость 0.1–0.25), синтез numpy под стиль.

**Режимы кадра (1080×1920, 30 к/с)**
- **A** — спикер на весь экран: хук и финал.
- **B** — сцена сверху (высота 1130), спикер в окне снизу.
- **C** — вставка на весь экран на самых сильных фразах.
- Пресеты долей:
  - «Говорящая голова»: A 40 / B 50 / C 10;
  - «Баланс» (по умолчанию): A 10 / B 60 / C 30;
  - «Визуальный»: A 5 / B 35 / C 60.
- Если C превышает долю пресета — разделить длинную сцену.
- Сцены режутся по словам-якорям: `wf(слово, вхождение)`.

**Окно спикера в B (как у Kallaway)**
- Окно: x=60, y=1390, ширина 960, радиус 54, низ уходит за край кадра. Без обводки, плашек и полосы.
- Внутри исходное видео (ширина 960, top=950).
- Поверх — вырезанный спикер (прозрачный webm). Голова и руки выходят за верх окна: clip-path видно выше окна и внутри, не по бокам.
- Градиент сцены 240 px в цвет подложки.
- Подложка с точечной сеткой: светлая (кремовая + лавандовые точки) или тёмная — по брифу.
- Окно въезжает пружиной (~60 px).

**Субтитры**
- По умолчанию 2 слова на экране. Фразы режутся по `. , : ? !`, через фразы не переносить.
- Второе слово пары не может быть предлогом или союзом (`в с и а на за из у со не к о от`) или числом, если во фразе осталось больше 2 слов: тогда пара из 1 слова.
- Склеивать имена в один токен («Claude Code»).
- Inter Tight 700, 56 px, letter-spacing −1.
- Цвет: на светлой подложке чёрный #1C1B22 (в A и C — на светлой плашке rgba(244,241,234,.94), радиус 18); на тёмной — белый с тенью.
- Строчные; аббревиатуры (ИИ, США) и слово призыва сохраняют регистр. Запятые оставлять, точки, двоеточия, ? и ! убирать.
- Без анимации и цветового акцента. Пара держится до следующей; если пауза больше 0.4 с — скрыть через 0.15 с.
- Позиция по y: B — 1150; A — около 1500; C — 1480–1560.

**Шрифты:** Inter Tight 700/600 и Noto Serif Display Italic, сжатый `font-stretch: 68%` (FontFace stretch `'62.5% 100%'`). Заголовок: гротеск + курсив с тонкой акцентной линией. Стилевой шрифт — только внутри сцен. Загрузка через FontFace + delayRender. Тексты на экране на русском.

## Сцены — всегда осмысленные
- **2D из слоёв (B):** фон + поза + предметы с пружиной + плашки. У сцены есть мини-сюжет (завязка → действие → итог за 3–5 с) и смена состояния на ключевом слове. Без звука должно быть понятно, что происходит. Не лепить стикеры поверх готовых иллюстраций.
- **Моушн-графика (B или C):** в 2–3 местах, где в тексте есть структура. В раскадровке описать тип блока (путь, сравнение, цикл, счётчик, график, список), элементы, что появляется на каком слове и чем блок заканчивается. Элементы крупные: узлы r 100–115, подписи 50 px. Готовые блоки — `library/motion.tsx`: MPath, MRace, MCycle.
- **3D кодом (C):** только из предметов и поз этого ролика, у каждой сцены есть метафора.
  - Пакеты: @remotion/three 4.0.300, three 0.169.0, @react-three/fiber 8.17.10, @react-three/drei 9.114.0.
  - Глиняный материал, тени, камера анимирована. Персонаж — вырезанная поза на плоскости.
  - Готовое в `library/three3d.tsx`: S3Orbit, S3Coaster, S3Jobs, S3Rocket, S3Laptop.
  - 3D-модели в сервисах не генерировать — собирать предметы в коде.
- **Свои видео, скриншоты, фото пользователя:** обработать под стиль (рамка, зерно, цвет, подписи).
- **Переходы:** цветная шторка-круг (±4 кадра) или пиксельная в игровых стилях.

## Техпроцесс
1. **Подготовка — одной командой** (подробно — docs/story-build.md). Google Диск в чате не открывать: пульт → «Материалы» → «Собрать пакет для монтажа» кладёт всю папку ролика на пульт.
   - `ArtifactData get projects/<id>` с out_dir=work/db; `Artifact read` path=<id> с out_dir=work/files — видео аватара (avatar.id) и каждая часть пакета (mediaPack.parts).
   - `python3 tools/reel_prep.py work/db/projects/<id>.json reels/NN-name --files work/files [--anims …]` в фоне, одно ожидание до конца. Делает папку из шаблона с общими пакетами, раскладку материалов, вырезку фона у поз и предметов, story.json, звуки монтажа, видео спикера ровно по паузам пульта (со spec — spec_build), вырезку спикера, если есть окно «Вырезка», лист work/prep_sheet.jpg и отчёт: какие сцены писать.
   - Упал — исправить причину и запустить ту же команду (сделанное пропускается). `--redo этап`, `--avatar файл` (видео больше 20 МБ прислали в чат), `--media папка`, `--no-matte`, `--plate-fix` (прилип фон над головой).
2. **Тайминги слов** приходят с пульта (по паузам и слогам). Числа и аббревиатуры, произнесённые иначе, править в words. Для шаблона со spec — распознавание речи внутри spec_build.
3. **Листы картинок** (2×2, 3×3 — отчёт reel_prep их отмечает) резать по ячейкам, обрезать по альфе, удалять фрагменты у края ячейки.
4. **Ручные инструменты** (cut_pauses, align, tools/matte, rembg) — только если reel_prep не справился с конкретным этапом.
5. **Лист подготовки** посмотреть один раз: прозрачность — пурпур, в конце кадры вырезки спикера (края, прилипший фон).
6. **Remotion.**
   - Шаблон `template/`: kit.tsx (Split, Title, Pop, Pill, Bg, Grain, Shake, wf), Scenes.tsx (BOUNDS/MODES/SCENES), Main.tsx (субтитры, переход, SFX).
   - Голос — один `<Audio>`, спикер в сценах — `OffthreadVideo muted startFrom`.
   - Длительность ограничить VIDEO_DUR.
7. **Рендер.** `tools/render.sh <dir> out.mp4 [--3d]` (concurrency 2; для 3D `--gl=swangle --timeout=120000`). Обычный ролик ~20 мин, с 3D ~40 мин, запускать в фоне и ждать окончания одним ожиданием (Monitor до появления out.mp4), а не проверять каждую минуту: каждая проверка — платный шаг чата.
8. **Проверка.** Стоп-кадры каждой сцены одним листом, кроп края вырезки, ebur128 ≈ −14 LUFS, доли A/B/C, длительность. Чинить, потом финал.
9. **Отдача.** SendUserFile с mp4, коротко: что сделано, где возможны неточности. Затем `python3 tools/reel_slim.py reels/NN-name`, commit + push в auto-editing.

## Экономия
- Картинки, которые чат посмотрел, остаются в контексте до конца чата и оплачиваются на каждом следующем шаге: кадры смотреть листом-сеткой, один раз, после цифровой проверки.
- Логи рендера, npm и распознавания обрезать до сути (`| tail`).
- Один ролик — один чат. Правки к готовому ролику после долгого монтажа — в новом чате с коротким заданием.

## Что спрашивать
- Стиль (варианты текстом), «ок» на раскадровку, «делай» на монтаж. Остальное — по брифу и умолчаниям.
- Когда пользователь просит «текстом / давай подумаем» — сначала план.
- Перед любой тратой кредитов в генеративных сервисах и загрузкой файлов наружу — назвать цель и цену, получить согласие.
