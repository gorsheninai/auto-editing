# Данные пульта

Читать, когда работаешь с проектом, шаблоном или блоками пульта через ArtifactData.

## Пульт монтажа
Интерфейс: https://claude.ai/artifact/5hvEdgNfsfN5esbxToxz9r (исходник — pult/pult.html, публиковать через Artifact с url).
Данные пульта (ArtifactData): projects (брифы роликов; поля script — текст, storyboard — раскадровка текстом, gptPrompt — один запрос для ChatGPT, refs — референсы (id ассетов пульта, читать через Artifact read с path=id), styleAnalysis — стиль ролика; avatar — видео аватара {id ассета или null, name, size}; drive — папка Диска с картинками; timing — хронометраж; segs — речевые куски исходника [нач, кон] в секундах (те же правила, что tools/cut_pauses.py); words — тайминги слов после вырезки и ускорения; sbRows — раскадровка сегментами [{text,s,e,wi:[первое,последнее слово в words],mode A/B/C,kind,win,media,note — что на экране}] (сегменты режутся по словам); kind: A — speaker; B — l2d (2D-сцена из картинок), gen (цельная картинка по смыслу от ChatGPT: картина, скриншот, документ — файл pic_N), motion (моушн-схема), d3 (3D кодом), media (файл пользователя с Диска); C — l2d (2D-сцена на весь экран, без окна спикера), motion (смысловой моушн), gen (картинка по смыслу на весь экран), d3 (3D-метафора), kinetic (кинетический текст), media; win (окно спикера в B): popout (вырезка), window (окно без вырезки), circle (кружок), strip (полоса снизу); media — имя файла в папке drive; mediaList — список вставок пользователя «имя — о чём»; win — окно по умолчанию; target — доли режимов {a,b,c}, sub — доли типов внутри B и C; subAnim/titleAnim — id анимации текста из коллекции textanims ('static' — наша статичная); ctaOn/ctaText — призыв в конце (по умолчанию ВЫКЛЮЧЕН: кодовое слово и призыв не добавлять); assetPlan — смысловой план картинок {entities (всё конкретное из текста: бренды, картины, люди, места — каждое получает картинку), cast (другие персонажи, не герой), blocks,poses,props,hands,people,backgrounds,pictures[{type product|painting|person|scene|screenshot|document|poster|place|news, entity, cast, hero}]}; герой — не больше трети картинок; бренды, картины и известные люди — по-настоящему, с логотипами (решение пользователя) (промпт для GPT пишется строго по нему); разбор и промпт пульт делает сам через Claude, в чате их можно доработать и записать обратно через update), templates, blocks, presets, textanims (анимации текста из референсов: {name, role subtitle|title, summary, font, params {unit, enter, duration_ms, stagger_ms, easing, overshoot, distance_px, start_scale, blur_px, emphasis, box, position, case, words_per_screen, color, exit}, previewId}; в монтаже — один компонент анимированного текста по params). Когда пользователь пишет «проект на пульте … id: X» — прочитай projects/X и работай по нему; по ходу обновляй поле status (draft → story → images → edit → done).
Коллекция templates в интерфейсе называется «Стили». «Новый ролик» сначала просит выбрать стиль (создаётся ролик quick:true с templateId) или «Без стиля» (полная карточка). Кнопка «Дополнить референсами» у стиля из премонтажа разбирает только новые ролики и обновляет тот же документ templates/<id> (refs дополняются, rules и рецепт пересобираются, rules.assets/assetsList/titleAnim сохраняются). В быстром режиме шаг «Картинки» показывается, только если в раскадровке есть l2d или gen. Анимацию текста можно снять из референса стиля в «Настроить» стиля: документ textanims получает templateId (projectId пустой) и выбирается в rules.subAnim/titleAnim. В запросы уходит только нужная часть стиля: раскадровка — без ЗВУК и ПОДАЧА РЕЧИ и без повтора трёх слоёв (sbStyle), картинки — только внешний вид (imgStyle); ассеты раздела «Референсы» в раскадровку не уходят.
Карточка ролика (с v39): Текст (+ «Мои вставки») → [Стиль, Настройки — только «Свои настройки» или без стиля] → Голос → Раскадровка (одна кнопка: сама считает тайминги, затем запрос Claude) → Картинки для GPT Image (всегда) → Материалы и задание (папка Диска; «Сохранить и скопировать задание» сохраняет, собирает mediaPack, если его нет или папка другая, и копирует задание).
Голос: avatar {id, name, size, kind: video|audio}. kind audio — озвучка без видео: tools/reel_prep.py делает из неё avatar.mp4 с чёрным кадром, раскадровка вся в режиме C.
Спикер в кадре: rules.speaker стиля (always | some | never), project.speaker перекрывает ('' — как в стиле). Если поля нет — вычисляется по разборам референсов (доля планов A/B < 8% → never), затем по rules.target и spec. Озвучка без видео всегда never. Раскадровка получает правило в запросе и потом жёстко правится (enforceSpeaker): never → все A/B в C, always → C в B.
Картинки стиля: rules.pictures (illustration — цельные иллюстрации-метафоры без героя, раскадровка ставит gen, l2d переводится в gen, план и промпт без героя; collage; mixed), иначе выводится из ядра стиля («нет человека»). Проект получает pictures, subPos (top|middle|bottom, поле стиля rules.subPos или subPosSet ролика), wipe (шторка-круг — только если rules.wipe или ролик включил; по умолчанию жёсткие склейки).
Картинки по смыслу привязаны к строкам: план даёт каждой картинке seg (номер сегмента), пульт пишет file=pic_N в план и media=pic_N в строку раскадровки; pult_to_story берёт файл по row.media, а pic_<номер строки> — только для старых проектов без привязки.
Данные блока в описании сегмента — до « // », пояснение после « // » в кадр не идёт (parseData).
gaps стиля (приёмы, которых нет в библиотеке) показываются в выборе стиля и в ролике; «Задание на недостающие блоки» копирует задание для чата.
Анимированная сцена (kind illu, стиль с pictures=illustration): строка раскадровки несёт objs [{what, move: pop|rise|drop|slide-l|slide-r|float|swing|spin|orbit|pulse|grow|shake|tip, place: center|left|right|top|bottom|back, size: big|mid|small}] (до 4), tone light|dark, ground, sc — номер листа. Промпт для GPT Image пульт собирает сам, без запроса Claude: лист объектов sc{N}.png на прозрачном фоне, объекты в ряд слева направо, без текста (подпапка 07_сцены). tools/reel_prep.py (этап scenes) режет лист на sc{N}_o{k}.png, pult_to_story пишет row.illu, шаблон рисует story/illu.tsx (фон тона стиля, «земля», появление и движение каждого объекта). Описание, начинающееся с кода блока библиотеки, остаётся блоком (motion).
Текст на картинках: фразы ролика на картинках не пишутся — текст даёт монтаж (субтитры, карточки, блоки).
Коллекция refanalyses — кэш разборов референсов премонтажа (ключ: имя+размер+дата файла; поле analysis). Пульт берёт оттуда готовый разбор, чтобы не платить за повтор. Чату её читать не нужно: те же разборы лежат в templates/<id>.refs[].analysis.
Поле проекта mediaPack {at, drive, parts — id JSON-частей пакета в assets пульта, files [{path,size}], skipped} — материалы с Диска, собранные кнопкой «Собрать пакет для монтажа»; раскладывает их tools/reel_prep.py.
Новые блоки после ролика: превью-клип (432×768, без звука) загрузить в assets пульта и добавить документ в blocks.
