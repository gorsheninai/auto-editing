# Премонтаж и глубокий разбор референсов

Читать для задания «Глубокий разбор» и для монтажа по шаблону с полем spec или rules.dna.

## Премонтаж из референсов (главная функция)
Шаблоны → «Новый премонтаж из референсов»: до 5 видео (≤20 МБ) → пульт замеряет склейки, планы, палитру, речь/паузы, подложку и удары на склейках → Claude разбирает кадры каждого ролика (REF_PROMPT) → синтез общего (SYNTH_PROMPT) → документ templates {kind:'premontage', refs[{id,name,metrics,sound,analysis}], recipe, soundNotes, speech, blockMap, gaps, deep, rules{style (стиль + рецепт + звук + подача), passport, win, bg, subAnim, target, punch, progress, speed, allowed}}. Референсы также в assets (section 'ref', Диск «08 Референсы»). Дальше «Создать монтаж» как у шаблона.
Глубокий разбор (кнопка на карточке → задание в чат) — конвейер из 7 разделов монтажа, всё в цифрах:
1. `python3 tools/ref_analyze.py ref.mp4 work/anN --lang en|ru` → report.json: склейки по всем кадрам (свой детектор), тип перехода, тип каждого плана (спикер/B-roll/скриншот/графика/карточка), лицо и крупность, камера (оптический поток), OCR-текст (кегль по высоте строчных, место, цвет, регистр, слов на экране, роль, анимация входа/выхода покадрово, опережение голоса), звук (LUFS, подложка, эффекты по полосам и их уровень к голосу), речь (распознавание sherpa-onnx, слова с таймингами), грейд (яркость, контраст, точки, насыщенность, тёплые тени/света, виньетка, зерно). Листы shots.jpg / title_N.jpg — проверить глазами.
2. `python3 tools/style_spec.py work/an*/report.json -o style_spec.json` → сводная спецификация + engine (значения для монтажа) + substitutes (чем заменять отсутствующее). Что проверено глазами — в manual_check.
3. Для ролика: `tools/asr.py avatar.mp4 src/words.json --script script.txt` (реальные тайминги слов, иначе рассинхрон), `tools/grade_match.py avatar.mp4 style_spec.json --refs work/an*/report.json --apply avatar_graded.mp4` (грейд с сохранением тона кожи), `tools/make_sfx.py public` + `tools/sound_levels.py avatar.mp4 public/sfx style_spec.json > levels.json` (громкость эффектов и подложки как у референса), раскадровка по engine.shots (доля спикера, длины планов, склейки на начале слов, смена крупности engine.crop), `tools/apply_spec.py <reel> style_spec.json --levels levels.json --avatar avatar_graded.mp4`.
4. Замкнутая проверка: `tools/ref_analyze.py out.mp4 work/an_out --lang ru` и `tools/compare_spec.py work/an_out/report.json style_spec.json` — таблица «референс / наш». Править, пока всё не в норме.
5. Шаблон с полем spec (глубокий разбор): «Создать монтаж» копирует spec в проект, ставит скорость 1.0, без наездов; раскадровку пульт просит по ритму референсов (доля спикера, длина вставок и планов, только жёсткие склейки, замены из substitutes). В чате: `pult_to_story.py` (пишет <ролик>/style_spec.json и индексы слов wi) → `python3 tools/spec_build.py <ролик> --src исходник.mp4` (вырезка пауз без ускорения, распознавание речи и перенос сегментов на реальные тайминги, укорачивание длинных вставок до insertMedian, резка длинных планов спикера по фразам с чередованием крупности, хук, грейд с тоном кожи, звуки и громкость, apply_spec) → свои сцены для вставок → рендер → `compare_spec.py report.json style_spec.json --video out.mp4 --story src/story.json` (кегль субтитров меряется по кадрам). Во вставках по спецификации row.clean=true: сцена без своих подписей, текст даёт только субтитр.
6. Стиль тремя слоями (главное, rules.dna шаблона): ЯДРО — что одинаково у всех референсов (держать во всём ролике), ПРИЁМЫ — словарь с кодами и правилом «когда» по смыслу текста (HOOK, WORD, NUM, KEY, CROP, BURST, LIST, BW, CARD; свои коды — новые блоки), СТРУКТУРА — части ролика (хук, раскрытие, примеры, финал) и ДИАПАЗОНЫ длин планов. Цифры (spec) — только для ядра. Разбор: `tools/style_dna.py work/an*/report.json -o dna_raw.json --timeline` (сравнение референсов между собой: ядро/меняется, приёмы с местом в ролике и словами, структура) → глазами по листам и ленте написать dna.json → `tools/dna_text.py dna.json` (текст; формат: строка на пункт, поля через « | », тот же на пульте) → rules.dna. Раскадровка пульта по dna: смысловые моменты → приёмы, поле tech у сегментов («[WORD,KEY] …» в описании). pult_to_story пишет <ролик>/style_dna.json; spec_build по нему режет планы по фразам в диапазонах, укорачивает вставки по длине приёма, ставит хук, крупные слова по номерам (keyIdx), ч/б, звуки по приёмам. Проверка: `tools/compare_dna.py <ролик> out.mp4 report.json` — ядро цифрами + приёмы (из словаря, без повторов подряд, частота) + структура (хук, финал, диапазоны).
Модели: ~/asr (sherpa-onnx zipformer ru/en и YuNet для лиц — с GitHub releases; HF закрыт). Записать в templates/<id>: rules.style, recipe, soundNotes, speech, rules.passport, spec (style_spec.json), deep:true.
