# Разбор стиля в чате → стилевой пакет

Читать по заданию пульта «Разбор стиля в чате» (кнопка «Разобрать в чате» на карточке стиля).
Цель — стиль референса **кодом Remotion**, а не описанием: субтитры, крупный текст, хук, склейки, камера, слои.
Пакет хранится на пульте (templates/<id>.stylePack), и любой монтаж в этом стиле ставит его код как есть
(tools/reel_prep.py, этап pack). Поэтому здесь можно и нужно смотреть кадры глазами и рендерить тесты:
этот чат делается один раз на стиль, а не на каждый ролик.

## Что такое пакет
Папка `work/pack/<slug>/`:
- `pack.tsx` — обязательно: `export const PACK_SLOTS: PackSlots = {…}`. Контракт слотов и пропсов —
  `template/src/story/pack/types.ts` (прочитай целиком). Слоты: Captions, Title, Hook, Camera, Cut (+cutLen), Overlay, Top, scenes.
  Пустой слот — работает стандартный блок шаблона, поэтому пиши только то, что у референса своё.
- помощники `*.tsx` / `*.ts` рядом (импорт `./имя`). Из шаблона можно импортировать `../types`, `../../blocks/*`, `../../remocn/*`, `remotion`, `@remotion/*`.
- `style.json` — `name`, `version`, `summary` (одна строка для карточки), `settings` (поверх settings ролика:
  `punch`, `wipe`, `subWords`, `subPos`, `subStyle`, `passport`, `musicVolume`, `insertZoomPerS`, `insertGrain`…),
  `check` (диапазоны для сверки готовых роликов), `slots`, `fonts`.
- `fonts/*.woff2` — шрифты, которых нет в шаблоне (список шаблона: FONT_LIB в template/src/blocks/style.ts).
  Взять из npm: `npm pack @fontsource/<имя>` → `package/files/<имя>-cyrillic-<вес>-normal.woff2` (и latin, если нужна латиница).
  В style.json: `"fonts": [{"family": "PackBebas", "weight": "400", "file": "bebas-cyr-400.woff2"}]`, в коде — `fontFamily: 'PackBebas'`.
  Шрифты из Google Fonts по сети при рендере не грузить: сети там нет.

Правила кода: кадр — чистая функция от `useCurrentFrame()` и пропсов (никаких `Math.random()` без сида, `Date`, fetch);
анимации — `interpolate` / `spring` с числами, снятыми с референса; размеры в пикселях кадра 1080×1920.

## Шаги
1. **Данные.** `ArtifactData get templates/<id>` с out_dir → `python3 tools/pult_brief.py <файл>`. Референсы: Artifact read (url пульта)
   с path=id и out_dir=work/refs. Если у стиля уже есть stylePack — скачай его файл и разверни: исходники лежат в `files` pack.json.
   `bash tools/setup.sh | tail -3` — модули, модели распознавания.
2. **Замеры цифрами** по каждому референсу:
   - `python3 tools/ref_analyze.py ref.mp4 work/anN --lang ru` → report.json (склейки, типы планов, камера, OCR-текст: кегль, место,
     цвет, регистр, вход/выход покадрово; звук; грейд). В чат целиком не выводить — читать скриптом нужные поля.
   - `python3 tools/style_pack.py measure ref.mp4` → склеек в минуту, яркость, насыщенность, контраст, LUFS.
3. **Глазами** — то, чего цифры не дают. Всё смотреть листами, по одной картинке:
   - текст: `tools/style_pack.py strip ref.mp4 -o work/s_text.jpg --from 3.2 --to 3.8 --crop 1080:500:0:1250` — каждый кадр входа слова.
     Записать: шрифт (или ближайший), вес, кегль, межбуквенное, регистр, обводка (толщина), тень, подложка (цвет, радиус, отступы),
     слов на экране, место по высоте, как выделено ударное слово, вход (тип, кадры, перелёт), выход, опережение голоса.
   - склейки: strip ±5 кадров вокруг каждой из первых 6–8 склеек (секунды — из report.json): жёсткая, вспышка, смаз, сдвиг, зум-толчок; сколько кадров.
   - камера: strip по 1 кадру из 3 (`--every 3`) на плане спикера: наезды, толчки на словах, тряска, смена крупности; сколько процентов и кадров.
   - хук и крупный текст: первые 2–3 секунды покадрово; карточки, стопки слов.
   - слои: зерно, виньетка, рамка, полосы, цвет теней и светов.
   Разбор пульта (refs[].analysis, rules.dna, spec) — подсказка, где искать; где расходится с кадрами — верить кадрам.
   Итог — короткий список «приём → числа» в work/pack/<slug>/NOTES.md (в пакет он не идёт, но нужен для следующей версии).
4. **Пакет кодом**: `work/pack/<slug>/pack.tsx` + style.json. Сначала субтитры и камера (их видно всё время), потом склейки, хук, Title, слои.
5. **Тест**: попроси у пользователя 10–20 с сырого видео (говорящая голова). Затем
   `python3 tools/style_pack.py build work/pack/<slug> -o work/pack.json`
   `python3 tools/style_pack.py testreel сырое.mp4 work/test --pack work/pack.json --dur 15` (в фоне; слова — tools/asr.py сам;
   свои сегменты — `--rows A:0-3,C:3-5,A:5-9`, хук — на первом сегменте, `--no-hook` убирает).
6. **Сверка, 2–4 круга**:
   - `tools/style_pack.py side ref.mp4 work/test/test.mp4 -o work/side.jpg --t <секунды, где на референсе текст/склейка/наезд>`;
     крупно текст: тот же side с `--crop 1080:500:0:1250`;
   - покадрово вход слова у нас (strip по test.mp4) против того же у референса — кадры входа должны совпасть ±1;
   - `tools/style_pack.py measure work/test/test.mp4` против цифр референса.
   Каждое расхождение — в правку кода с числом («вход 8 кадров → 4», «обводка 4 → 7 px»), пересобрать build + testreel.
   Тест — на чужом видео, поэтому сюжет и цвет кожи не сравнивать, сравнивать приёмы.
7. **Показать пользователю**: SendUserFile — side-лист и test.mp4, 2–3 строки, что повторено и чего нет (и почему). Ждать «да».
   Без «да» в пульт ничего не писать.
8. **После «да» — сохранить в пульт**:
   - эталон: лист 2×6 «референс сверху / тест снизу» (`side … --n 6`) → work/sheet.jpg;
   - `check` в style.json — диапазоны для будущих роликов: `cutsPerMin` [0,6×; 1,5× референса], `luma`/`sat`/`contrast` ±20% от теста
     (цифры теста, а не референса: цвет зависит от исходника пользователя). Пересобрать build.
   - загрузить в ассеты пульта (Artifact, action publish, url пульта, asset: true): sheet.jpg, затем pack.json отдельным вызовом
     (текстовый файл — всегда один в вызове). Если откажет из-за того, что пульт не прочитан в этом чате, — Artifact read url пульта без path и повторить.
   - id эталона записать в style.json → `sheet`, пересобрать build, загрузить pack.json ещё раз (id файла — новый).
   - `ArtifactData update templates/<id>`: `stylePack = {v, file: id pack.json, sheet: id листа, at: ISO-дата, summary, slots}`;
     прошлый stylePack (если был) — в начало массива `stylePacks` (не больше 10). Уточнённые цифры — в spec / rules.dna, если замеры их поправили.
   - если есть доступ на запись в репозиторий: исходники пакета и NOTES.md → library/styles/<slug>/, коммит (без work/ и видео).
9. Ответ пользователю: одна строка — «стиль v<N> сохранён в пульт»; ролики в этом стиле теперь собираются его кодом.

## Как пакет попадает в ролик
Новый ролик в стиле получает `stylePack` с карточки стиля; задание монтажа всегда берёт последнюю версию с карточки
(`--pack-id`), Artifact read кладёт pack.json и эталон в work/files. reel_prep (этап pack) ставит код в src/story/pack/,
шрифты — в public/fonts/pack/. После рендера reel_go запускает `style_pack.py check`: цифры против `check`, лист
work/style_check.jpg (сверху эталон, снизу наш). Вне диапазонов — «Не сошлось со стилем».
