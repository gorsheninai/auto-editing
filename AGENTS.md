# auto-editing — инструкция для Codex

Этот репозиторий (`gorsheninai/auto-editing`, «Reels Studio») — студия монтажа вертикальных рилсов с ИИ-аватаром: шаблон Remotion, библиотека моушн-/3D-блоков, скрипты и ролики. Раньше она работала в Claude, поэтому главный свод правил — `CLAUDE.md`. **Прочитай `CLAUDE.md` и `README.md` перед первой задачей и работай по ним;** подробные правила под задачу — в `docs/` (таблица «Что читать под задачу» в `CLAUDE.md`). Этот файл только переводит их на инструменты Codex.

Пользователь пишет по-русски — отвечай по-русски, коротко.

## Первое действие

1. `bash tools/setup.sh` — Python-модули, `npm` в `template/`, модели (`reel_prep.py` и `reel_go.py` вызывают его сами).
2. Новый ролик без пульта: `README.md` → «Новый ролик» и `brief.md`. Ролик кладётся в `reels/NN-name/`.

## Навыки

`.agents/skills/` — Codex подхватывает их сам; явный вызов `$имя`.

| Навык | Когда |
| --- | --- |
| `reel-montage-popout` | монтаж рилса из видео с аватаром по шаблону из 9 шагов: паузы, ускорение, режимы A/B/C, спикер в окне, субтитры, 2D/моушн/3D-сцены |
| `gpt-image-batch-prompts` | один большой запрос в ChatGPT (GPT Image) на персонажа, предметы и фоны ролика |
| `collage-reel` | рилс «бумажный сюр»: 3D-герой-наклейка, коллаж, буквы-вырезки |

Новая студия с моушен-сценами, стилями монтажа, мультиками и 3D — соседний репозиторий `gorsheninai/video-studio` (у него свой `AGENTS.md`).

## Правила

- Ролики (`reels/*`) в git не хранятся; коммитятся только правки инструментов, шаблона, библиотеки, пульта.
- `library/CATALOG.md` целиком не читать — `library/INDEX.md` и поиск по коду; после правки — `python3 tools/catalog_index.py`.
- Перед тратой кредитов в генеративных сервисах — спросить пользователя. 3D-модели не генерировать, собирать в коде.
- Рендер — `tools/render.sh` (с `--3d` для 3D-сцен), лог в `render.log`; вывод команд обрезать `| tail`.
- Удачные блоки переносить в `library/` только по просьбе пользователя.
- Чтобы навыки работали и вне репозитория: `bash tools/install_codex_skills.sh`.
