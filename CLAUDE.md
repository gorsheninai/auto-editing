# auto-editing — студия монтажа рилсов

Пульт: https://claude.ai/artifact/5hvEdgNfsfN5esbxToxz9r — данные через ArtifactData, файлы через Artifact read с path. Коннекторы для пульта не нужны: не ищи их и не предлагай (SearchMcpRegistry/SuggestConnectors не вызывать), даже если задание кажется неполным.
Правила монтажа — в скилле reel-montage-popout, промпты для картинок — в скилле gpt-image-batch-prompts.
Новый ролик кладётся в reels/NN-name/. Видео и картинки в git не коммитить — они лежат на Google Диске.
После ролика: удачные новые блоки перенести в library/ и CATALOG.md (`python3 tools/catalog_index.py`), убрать копии шаблона `python3 tools/reel_slim.py reels/NN-name`, закоммитить и запушить в main.
Перед тратой кредитов в генеративных сервисах — спрашивать пользователя. 3D-модели не генерировать, собирать в коде.
Когда пользователь пишет «проект на пульте … id: X» — прочитай projects/X и работай по нему; по ходу обновляй поле status (draft → story → images → edit → done).

## Что читать под задачу
Подробные правила разложены по файлам. Читай только то, что нужно для текущей задачи, — полностью, без пропусков.
| Задача | Файлы |
|---|---|
| Любая работа с проектом, шаблоном, блоками пульта | docs/pult-data.md |
| Новый ролик с нуля (без пульта) | README.md, brief.md |
| Сборка ролика по раскадровке пульта | docs/pult-data.md, docs/story-build.md |
| В задании указан шаблон, или пишешь новые блоки | docs/template-montage.md |
| «Глубокий разбор» премонтажа; шаблон с полем spec или rules.dna | docs/deep-analysis.md |
| В раскадровке коды ассетов, вкладка «Ассеты» | docs/assets.md |

## Экономия контекста
- **Каталог блоков** library/CATALOG.md большой — целиком не читать никогда, даже если скилл или старое задание велит. Для подбора блоков на всю раскадровку — library/INDEX.md (код, суть, «для чего»); полное описание и формат нужного блока — Grep по коду в CATALOG.md. После правки CATALOG.md: `python3 tools/catalog_index.py`.
- **Старые ролики** хранят только свои файлы, копии шаблона из них убраны. Код блоков искать в template/ и library/, не в reels/. Перерендерить старый ролик: `python3 tools/reel_slim.py reels/NN-name --restore` → npm ci → рендер.
- **Пульт** правится по частям: исходник разрезан на pult/src/*.html по разделам кода (ролики, материалы, референсы и промпт, премонтаж, монтаж по шаблону, шаблоны, библиотека, ассеты, Диск, пресеты, данные). Нужное место найти Grep по pult/src, читать и править только эту часть, затем `python3 tools/build_pult.py` и опубликовать pult/pult.html через Artifact с url пульта. pult/pult.html и опубликованный пульт целиком не читать. Перед публикацией `python3 tools/build_pult.py --check`.
- **Данные пульта** (ArtifactData get/list) сохранять в файл и разбирать скриптом или Grep, не выводить документ в чат целиком: в проектах большие поля words, segs, sbRows.
- **Проверка кадров**: несколько стоп-кадров склеивать в один лист-сетку (ffmpeg tile) и смотреть его одной картинкой. Сначала цифровая сверка (compare_spec, compare_dna), глазами — то, что она не покрывает или где не сошлось.
- **Вывод команд** (рендер, npm, распознавание) обрезать до сути: `| tail`, без полных логов.
