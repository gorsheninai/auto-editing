# auto-editing — студия монтажа рилсов

Перед работой прочитай README.md (структура и порядок нового ролика), brief.md (параметры и значения по умолчанию) и library/CATALOG.md (готовые сцены).
Правила монтажа — в скилле reel-montage-popout, промпты для картинок — в скилле gpt-image-batch-prompts.
Новый ролик кладётся в reels/NN-name/. Видео и картинки в git не коммитить — они лежат на Google Диске.
После ролика: удачные новые блоки перенести в library/ и CATALOG.md, закоммитить и запушить в main.
Перед тратой кредитов в генеративных сервисах — спрашивать пользователя. 3D-модели не генерировать, собирать в коде.

## Пульт монтажа
Интерфейс: https://claude.ai/artifact/5hvEdgNfsfN5esbxToxz9r (исходник — pult/pult.html, публиковать через Artifact с url).
Данные пульта (ArtifactData): projects (брифы роликов; поля script — текст, storyboard — раскадровка текстом, gptPrompt — один запрос для ChatGPT, refs — референсы (id ассетов пульта, читать через Artifact read с path=id), styleAnalysis — стиль ролика; avatar — видео аватара {id ассета или null, name, size}; drive — папка Диска с картинками; timing — хронометраж; segs — речевые куски исходника [нач, кон] в секундах (те же правила, что tools/cut_pauses.py); words — тайминги слов после вырезки и ускорения; sbRows — раскадровка сегментами [{text,s,e,wi:[первое,последнее слово в words],mode A/B/C,kind,win,media,note — что на экране}] (сегменты режутся по словам); kind: A — speaker; B — l2d (2D-сцена из картинок), gen (цельная картинка по смыслу от ChatGPT: картина, скриншот, документ — файл pic_N), motion (моушн-схема), d3 (3D кодом), media (файл пользователя с Диска); C — l2d (2D-сцена на весь экран, без окна спикера), motion (смысловой моушн), gen (картинка по смыслу на весь экран), d3 (3D-метафора), kinetic (кинетический текст), media; win (окно спикера в B): popout (вырезка), window (окно без вырезки), circle (кружок), strip (полоса снизу); media — имя файла в папке drive; mediaList — список вставок пользователя «имя — о чём»; win — окно по умолчанию; target — доли режимов {a,b,c}, sub — доли типов внутри B и C; subAnim/titleAnim — id анимации текста из коллекции textanims ('static' — наша статичная); ctaOn/ctaText — призыв в конце (по умолчанию ВЫКЛЮЧЕН: кодовое слово и призыв не добавлять); assetPlan — смысловой план картинок {entities (всё конкретное из текста: бренды, картины, люди, места — каждое получает картинку), cast (другие персонажи, не герой), blocks,poses,props,hands,people,backgrounds,pictures[{type product|painting|person|scene|screenshot|document|poster|place|news, entity, cast, hero}]}; герой — не больше трети картинок; бренды, картины и известные люди — по-настоящему, с логотипами (решение пользователя) (промпт для GPT пишется строго по нему); разбор и промпт пульт делает сам через Claude, в чате их можно доработать и записать обратно через update), templates, blocks, presets, textanims (анимации текста из референсов: {name, role subtitle|title, summary, font, params {unit, enter, duration_ms, stagger_ms, easing, overshoot, distance_px, start_scale, blur_px, emphasis, box, position, case, words_per_screen, color, exit}, previewId}; в монтаже — один компонент анимированного текста по params). Когда пользователь пишет «проект на пульте … id: X» — прочитай projects/X и работай по нему; по ходу обновляй поле status (draft → story → images → edit → done).
Новые блоки после ролика: превью-клип (432×768, без звука) загрузить в assets пульта и добавить документ в blocks.

## Монтаж по шаблону
Документ templates может иметь rules {style, win, bg, subAnim, titleAnim, target {a,b,c} или null, punch, progress, assets — папка Диска с базовыми ассетами стиля, assetsList — «имя — о чём», allowed — коды разрешённых блоков, [] = все}. Кнопка «Создать монтаж» на карточке создаёт проект с templateId, quick:true, mode auto|own и полями из rules (styleAnalysis = rules.style). Раскадровку пульт собирает сам только из allowed. rules.passport — стилевой паспорт {colors {bg,ink,muted,accent,accent2,card,soft}, fonts {sans,serif,hand} — id из template/src/blocks/style.ts FONT_LIB, radius 0.3–1.6, motion soft|spring|snappy, texture dots|clean|paper|grain, shadow}; копируется в projects.passport → pult_to_story.py → story.json settings.passport. Все блоки берут из него цвета (themeFrom), шрифты (CSS-переменные --f-sans/--f-serif/--f-hand), скругления (rad), тени (shd) и характер движения (spring/ramp из kit). Новые блоки писать так же: цвета из theme, шрифты SANS/SERIF/HAND, borderRadius: rad(n), boxShadow: shd(…), spring из ./kit. Если в задании указан шаблон: блоки брать только из allowed, ассеты из rules.assets скачать в public/media/ вместе с картинками ролика.

## Ассеты
Коллекция assets на пульте: {code (имя для раскадровки), name, section overlay|broll|photo|graphic|sound|font|lut, group, when, tags, license, source, drive — ссылка на Диск, fileId — файл на пульте (читать через Artifact read с path=fileId), fileKind, fileName, size}. Оригиналы — Диск «Библиотека ассетов» (https://drive.google.com/drive/folders/1msXBtJaeY4AnzL5Y7bN6KQ2es2lCPpbm, подпапки 01 Видео-оверлеи … 07 Цвет и LUT). Звук пульт не хранит — только на Диске. Вкладка «Ассеты» сама подтягивает новые файлы из подпапок Диска (коннектор Google Drive в пульте): карточка с driveId, оригинал до 20 МБ — в fileId, превью-клип 432×768 webm — в previewId; убранные с пульта карточки помечаются hidden:true. В git медиа не класть. Код ассета в описании сегмента → скачать файл в public/media/ ролика и вставить по смыслу.
Блоки библиотеки имеют поле group (подгруппа внутри kind); стили субтитров Sub… — в textanims с полем group.

## Материалы на Диске
Промпт для ChatGPT заканчивается блоком СОХРАНЕНИЕ: ChatGPT кладёт картинки в «Ролики/<дата> <название>/» с подпапками 01_персонаж, 02_предметы, 03_люди, 04_фоны, 05_смысловые, 06_мои_вставки (запасной вариант — ZIP с той же структурой). Для монтажа всю папку ролика скачать в reels/NN/public/media/ как есть — pult_to_story.py ищет файлы по имени во всех подпапках.

## Сборка по раскадровке (композиция Story)
1. Проект пульта → `ArtifactData get projects/<id>` в файл, `ArtifactData list textanims` в файл.
2. `python3 tools/pult_to_story.py project.json reels/NN-name --anims textanims.json` → src/story.json и src/words.json, плюс список сегментов, которым нужна своя сцена.
3. Код в template/src/story/: windows.tsx (окна спикера popout/window/circle/strip), textanim.tsx (AnimText по params), inserts.tsx (KineticText; PicInsert с рамками phone/window/painting/product/poster/plain — выбор по note; LayerScene; Placeholder), registry.tsx (свои сцены: row.scene → компонент), StoryMain.tsx.
4. Готовые блоки библиотеки (template/src/blocks, список — library/CATALOG.md «Библиотека блоков», коды — blocks/codes.json) подключены сами: код в начале описания сегмента → scene, Tr… → tr, Fx… → fx, Ink…/PaperSticker → ov, стиль субтитров Sub… → settings.subAnim.style, подложка «живой градиент» → backdrop BgGrain. Свои сцены motion/d3 и 2D с сюжетом пишутся в registry.tsx и указываются в story.json полем scene; без сцены motion/d3 показывают кинетический текст, l2d без layer — заглушку (в финал не должна попасть).
5. Проверка стоп-кадрами, затем `COMP=Story tools/render.sh reels/NN-name out.mp4 [--3d]`.
